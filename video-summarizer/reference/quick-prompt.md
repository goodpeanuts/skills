# 快速简报

完整阅读字幕/转写、视频详情/简介/标签/章节和本次有效的观众反馈，写一篇精炼中文简报。字幕覆盖全片；不通过只读首尾或截断长字幕节省工作。

只使用文本资料，不读关键帧、已有标准总结及其画面观察。不推断画面上的界面、数据、效果。评论观点需注明观众来源，不冒充视频事实；无有效口播文本时拒绝编造内容。

正文包含H1视频标题及技能规定的元数据顶行。开头注明“基于字幕及文本资料生成，未分析画面”。之后按内容需要组织：

- 一句话结论与主要收获。
- 核心观点、方法、证据或结果，优先保留关键数字和限制。
- 有价值的观众补充、共识、质疑；没有则省略。
- 值得继续观看的段落、资源或尚未回答的问题；只有可靠字幕锚点时标时间。

避免逐段长篇展开，不以固定字数截断必要信息。与标准总结共用模型/Harness署名规则、来源纪律和writing-style.md行文基线；不嵌帧图片。把正文写到交接的summary_output，文本溯源底稿写到evidence_output，由finish发布。
