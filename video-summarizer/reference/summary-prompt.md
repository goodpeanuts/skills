## 2. 一句话结论（TL;DR）
用 2-4 句话给出视频的核心结论。**只能来自正片中已经展开论证的内容**——片头悬念钩子、预告、"看到最后"之类的话不得进入 TL;DR。

## 3. 概述（Overview）
用一段话概括：视频的核心论题是什么、作者沿着什么路径论证/演示、最终得出了什么结论、适合谁看。

## 4. 主题分解（Thematic Breakdown）

分段规则：
- 若上方「官方章节」非空：**必须按官方章节原标题组织本节**，输出顺序与原章节一致，不得自行重新分段、合并或改名；原章节标题保留原文，可加中文注释。
- 若官方章节为空：按内容主题自行分段，并在本节开头注明「原片无官方章节，以下为按主题划分」。

每个小节必须包含：
- **小节标题** + 覆盖的时间范围（如 `[12:34–25:10]`）
- **详尽展开**该节内容——目标是读者无需再看视频即可完全理解；出现的方法、框架、流程、操作步骤，写成分步说明或结构化列表，不要压缩成一句话
- 保留**关键数据、数字、对比、定义和条件**（例如"仅在 X 情况下成立"）
- 该节中值得保留的**直接引语**单独引用并附时间戳

## 严格规则（违反任何一条即为失败）

1. **忠于原文**：所有事实只能来自上面的字幕文本；不得引入外部知识，不得根据标题或常识脑补。
2. **口播是唯一证据**：字幕里没说的内容不写；描述区/评论区信息本提示词未提供，不得引用。
3. **时间戳纪律**：时间戳 = 该论点在口播中**开始被说出**的时间，格式 `m:ss` 或 `h:mm:ss`；禁止"大约"、"前后"等模糊表述。
4. **不修正字幕错误**：明显错词保留原样并写成「原字幕『X』（可能是 Y，m:ss）」；不确定就标「待核实」，禁止按常识"圆"成正确术语。
5. **剜掉赞助口播**：忽略"由…赞助"段、优惠码、联盟链接；若赞助段中夹有有效演示，只保留演示内容并标注「夹在赞助段」。
6. **忽略噪音**：片头悬念、片尾订阅/点赞呼吁、下次预告不进入任何小节和 TL;DR。
7. **无有效口播时拒绝编造**：若文本只有 [Music]/[Applause]/字幕卡等无实质内容，不要写内容总结——只输出：失败原因、可看到的章节原文、以及建议（如改用转录模式）。
8. **详尽优先**：本模式的哲学是 *Prioritize detail over brevity*——追求视频的完整书面等价物，不做过度压缩；长段落拆成短段或列表以保证可读性。
