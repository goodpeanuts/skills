## 证据法则（先读这个再写）

三类证据源，职责不同：

1. **口播字幕**（主源）：一切事实主张的默认依据，引用时附时间戳。
2. **关键帧观察**（补源）：只补口播没讲的信息（界面路径、图表数据、演示效果、画面文字）；口播已讲过的不重复。
3. **观众反馈**（辅源）：用于洞察（共识、质疑、争议、受众画像、内容边界），不得与正片内容混同；观众与正片矛盾时在正文直接并列陈述并注明"视频称 X，观众实测/质疑 Y"。

**正文零证据痕迹**：summary 中不得出现 `[画面]` `[评论]` `[弹幕]` 标记、赞数、弹幕条数统计、评论原文整段引用。所有溯源细节写入 evidence.md（另有模板），总结正文只保留消化后的结论性陈述。视频时间戳（`m:ss`）属于读者导航，正常使用。

## 输出格式

章节分**必选**与**弹性**两类。弹性章节按触发条件表增减，实际出现的章节按顺序连续编号；触发边缘情况由你按内容微调（规则表是默认，不是铁律），但**不得为凑格式而保留无内容的章节**。

| 章节 | 必选性 | 触发条件与写作要求 |
|------|--------|--------------------|
| 元数据 | **必选** | 标题/平台/链接/时长/语言/总结时间 |
| 一句话结论（TL;DR） | **必选** | 2-4 句核心结论，只能来自正片已展开论证的内容 |
| 概述 | 弹性 | 时长 ≥5 分钟才单列（短视频并入 TL;DR）：核心论题、论证路径、结论、适合谁看 |
| 时间线分解 | **必选** | 正文主体，见下方详细规则 |
| 框架与方法论 | 弹性 | 视频呈现了可复用的框架/模型/决策逻辑时：结构化说明组成部分、适用场景；无则整章不出现 |
| 观众反馈洞察 | 弹性 | 弹幕/评论存在且有信号时：只写洞察——共识、质疑、争议、受众画像、观众实测补充；信号弱缩为概述里一句话 |
| 收获与行动 | 弹性 | 教程/可操作类：决策对比、建议路径、适用前提与风险边界；纯娱乐/资讯类不出现 |
| 只看 N 分钟 | 弹性 | 时长 >15 分钟：给出唯一必看的连续时间范围（N 按视频时长自适应，如 30 分钟视频给 8 分钟段）及理由 |
| 线索与延伸 | 弹性 | 存在线索即出现：视频实际提及的工具/资源/人物、UP 主补充的入口、观众讨论指向的深挖方向，混排成清单 |

### 时间线分解详细规则

- 官方章节非空时**必须按官方章节原标题组织**，顺序一致，不改名不合并（原题保留原文可加中文注释）。
- 无官方章节时按内容主题自行分段，开头注明「原片无官方章节，以下为按主题划分」。
- 分段粒度随时长缩放：约 5 分钟内 2-4 段；30 分钟级 5-8 段或按章节；2 小时级章节+子段。内容丰富度优先于时长（信息密集的 3 分钟也可分 4 段）。
- 每个小节：**小节标题 + 时间范围**（如 `[12:34–25:10]`）+ 详尽展开——目标是读者无需再看视频即可完全理解；方法/流程/操作写成分步说明或结构化列表，不压缩成一句话。
- 保留**关键数据、数字、对比、定义和条件**（"仅在 X 情况下成立"）。
- 关键帧观察到的画面信息（口播未讲的）直接融入对应小节成文。
- 该节值得保留的**直接引语**随文引用并附时间戳（`> "引语" — m:ss`），只收确实说过的话——全片最值得记住的几句自然分布在这里，不再另设引语章。
- 弹幕高能时刻若与某小节对应，可在该节自然带出观众反应的结论（不引统计数字）。

## 严格规则（违反任何一条即为失败）

1. **忠于证据**：所有事实只能来自口播、关键帧观察、观众反馈三类输入；不得引入外部知识，不得脑补。
2. **证据消化**：画面与观众信息入文时必须是结论性陈述，不得伪装成视频原话；与口播矛盾时并列呈现并标明各自来源属性。
3. **正文零证据痕迹**：无标记、无赞数、无弹幕统计、无评论原文整段引用（观众观点的简短转述允许，如"有观众实测…"）。
4. **时间戳纪律**：时间戳 = 论点开始被说出的时间，格式 `m:ss` / `h:mm:ss`；禁止"大约""前后"。
5. **不修正字幕错误**：明显错词保留原样并写成「原字幕『X』（可能是 Y，m:ss）」；不确定标「待核实」。
6. **剜掉赞助口播**：忽略赞助段、优惠码、联盟链接；赞助段夹的有效演示只保留演示内容并注明「夹在赞助段」。
7. **忽略噪音**：片头悬念、片尾订阅点赞、下次预告不进入任何章节和 TL;DR。
8. **无有效口播时拒绝编造**：若文本只有 [Music]/[Applause]/字幕卡等无实质内容，不要写内容总结——输出失败原因、可见章节原文、建议（改用转录模式）。
9. **弹性防硬凑**：触发条件不满足的弹性章节直接缺席；满足但无内容的也缺席。
10. **详尽优先**：本模式哲学是 *Prioritize detail over brevity*——追求视频的完整书面等价物；长段拆短段或列表保证可读性；总量随弹性章节与视频时长自适应。
