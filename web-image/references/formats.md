# 尺寸规格表

> 画板必须用**真实像素**定义（`data-w` / `data-h`），预览缩放由工作台负责。
> 拿不准就按下表选，不要自己发明尺寸。

## 快速决策

| 用户说 | 用这个预设 |
|---|---|
| 头像 / 图标 / logo | `avatar` 1024×1024 |
| 发朋友圈 / 发 IG / 方图 | `square` 1080×1080 |
| 小红书 / 竖版封面 | `xhs` 1080×1440 |
| 抖音 / Story / 手机壁纸 | `story` 1080×1920 |
| 公众号封面（头条） | `wechat` 900×383 |
| 分享出去的链接预览图 / OG | `og` 1200×630 |
| Banner / 横幅 / 站点头图 | `banner` 1500×600 |
| X（推特）主页头图 | `x-header` 1500×500 |
| 视频封面 / 缩略图 | `thumb` 1280×720 |
| 幻灯片 / 演示页 | `slide` 1920×1080 |
| 要打印 / 要发 PDF | `a4` 2480×3508 |

## 完整规格

### 1:1 方形
| 预设 | 像素 | 用在哪 | 注意 |
|---|---|---|---|
| `avatar` | 1024×1024 | 社交头像、App Icon、组织标识、GitHub 头像 | 会被裁成圆形——**主体收进中心 80% 的圆内**，四角别放东西 |
| `square` | 1080×1080 | 朋友圈、Instagram 方图、小红书方图、Facebook 帖子 | 信息流里会被压到 ~350px 宽，最小字号 ≥ 画板高的 3% |
| `podcast` | 3000×3000 | 播客封面（Apple Podcasts 要求 1400–3000） | 只放标题 + 标记，缩到 55px 也要认得出 |
| `wechat-sub` | 500×500 | 公众号次条封面 | 实际展示约 200px，别放正文 |

### 竖版
| 预设 | 像素 | 比例 | 用在哪 | 安全区 |
|---|---|---|---|---|
| `xhs` | 1080×1440 | 3:4 | 小红书首图、Pinterest | **底部 18% 会被标题和头像盖住**，别放关键信息 |
| `ig-portrait` | 1080×1350 | 4:5 | Instagram 竖图（信息流占屏最大） | — |
| `story` | 1080×1920 | 9:16 | 抖音/快手封面、IG Story、Reels、手机壁纸 | 上下各留 15% 给系统 UI 和平台控件 |
| `pin` | 1200×1800 | 2:3 | Pinterest 推荐比例 | — |

### 横版
| 预设 | 像素 | 比例 | 用在哪 | 注意 |
|---|---|---|---|---|
| `og` | 1200×630 | 1.91:1 | OG 图、Twitter large card、微信/飞书/Slack 链接预览 | 各平台裁切不同，**四边留 8% 出血余量** |
| `wechat` | 900×383 | 2.35:1 | 微信公众号头条封面 | 列表页会裁成 1:1 取**中间**——重要元素放中轴 |
| `banner` | 1500×600 | 5:2 | **X/Twitter 文章封面**、网站 Hero、邮件头图、通用横幅 | X 文章页按原比例显示；但进信息流卡片会裁成 16:9（左右各切 ~14%），关键信息别贴左右边 |
| `x-header` | 1500×500 | 3:1 | X/Twitter 个人主页头图 | **左下角被头像盖住**（约 200×200），右下角有按钮 |
| `gh-social` | 1280×640 | 2:1 | GitHub 仓库社交预览图 | — |
| `thumb` | 1280×720 | 16:9 | YouTube / B站封面、视频缩略图 | 右下角有时长角标；文字要能在 210px 宽时读清 |
| `bili` | 1146×717 | 1.6:1 | B站视频封面官方尺寸 | — |
| `slide` | 1920×1080 | 16:9 | 演示页、录屏封面、Keynote 导出 | 正文字号 ≥ 28px |

### 打印
| 预设 | 像素 | 说明 |
|---|---|---|
| `a4` | 2480×3508 | A4 竖版 @300dpi。要小文件用 1240×1754 @150dpi |
| `a4-land` | 3508×2480 | A4 横版 |
| `a3` | 3508×4961 | A3 海报 @300dpi |
| `card` | 1063×638 | 名片 90×54mm @300dpi。四周留 3mm(≈35px) 出血 |

**打印换算**：像素 = 毫米 ÷ 25.4 × dpi。打印稿一律 300dpi，且**字号按毫米反推**——A4 上的正文 10pt ≈ 42px。

## 通用规则

1. **一次只出一个尺寸的一张图**，需要多平台就并排放多张画板，而不是做一张"通用图"。
2. **导出 2x**：所有屏幕用图导出 2x（工作台默认），打印稿用 1x 但画板本身就是 300dpi 像素。
3. **边距 = 短边 × 6%~9%**。1080 方图 → 72~96px。别小于这个数，图会显得挤。
4. **最小字号 = 短边 × 2.5%**。1080 方图 → 27px。低于这个数在信息流缩略图里就糊了。
5. **主标题 = 短边 × 10%~18%**。要的是一眼看到，不是排版整齐。
