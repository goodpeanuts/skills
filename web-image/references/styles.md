# 风格库

32 套有明确出身的风格。**每套都有一个"签名手法"——那一招才是风格的辨识度所在**，
配色只是入场券。用户指定风格时按 slug 或别名对号入座；没指定时从「推荐话术」里挑 3~4 个问他。

样张：`examples/styles.html` —— 32 套各用**它最擅长的画幅和真实场景文案**，
覆盖 3:4 / 1.91:1 / 1:1 / 9:16 / 5:2 / 16:9 / 2.35:1 七种画幅，可直接打开对比和导出。
照抄样张时**连文案一起换掉**——样张里的文案是示范"具体"长什么样，不是模板。

## 印刷传统

### `swiss` 瑞士国际主义 · Swiss / International Style
> 别名：国际主义、网格设计、Helvetica 风、包豪斯后现代
> 气质：理性、克制、专业。看起来像一份"正确"的东西。
> 出身：Müller-Brockmann、Vignelli；今天的 Vercel、Linear 都在吃这套的红利。

```css
--bg:#ffffff; --ink:#111111; --sub:#6b6b6b; --accent:#e4002b; --line:#dcdcdc;
/* 无衬线，字重只用 400 和 700，不用中间值 */
```
**签名手法**：一条贯穿画板的 1px 横线，把标题和内容切开；所有元素严格对齐到 12 栏；
编号用 `01 / 04` 的形式放在角落。红色**整张图只出现一次**。
**常用画幅**：1.91:1 OG · 5:2 横幅 · A4 打印
**适合**：产品发布、作品集、B端、数据、打印稿。 **不适合**：需要温度的内容。

### `editorial` 杂志编辑部 · Editorial
> 别名：杂志风、刊物风、长文封面
> 气质：有观点、有分量、值得坐下来读。
> 出身：Monocle、纽约客、Kinfolk。

```css
--bg:#f4f1ea; --ink:#16160f; --sub:#6a675c; --accent:#a8331f; --line:#d5d0c3;
/* 标题衬线，眉标/落款等宽或小型大写 */
```
**签名手法**：首字下沉（drop cap，3 行高的衬线大字）+ 顶部一行细线夹着的栏目名（大写、字距 .2em）
+ 竖向 hairline 分栏。标题用衬线，其余全部用小号无衬线拉开反差。
**常用画幅**：3:4 竖版封面 · 1.91:1
**适合**：长文封面、观点输出、书单、简报、专栏。

### `newsprint` 报纸 · Newsprint
> 别名：报刊、老报纸、号外
> 气质：紧迫、权威、信息密度高。
> 出身：泰晤士报报头、旧金山纪事报。

```css
--bg:#f0ede6; --ink:#14140f; --sub:#585448; --rule:#14140f;
/* 全部单色，靠字号和字重分层。标题用粗衬线 */
```
**签名手法**：报头式三层横线（粗 4px / 空 3px / 细 1px）；日期和期号分列在报头两端；
正文分 2~3 栏，栏间 1px 竖线；叠一层网点纹理（`radial-gradient` 1px 点阵）模拟印刷。
**常用画幅**：1.91:1 · A4
**适合**：宣言式内容、盘点、年终总结、复古活动。

### `blueprint` 工程蓝图 · Blueprint
> 别名：蓝图、图纸、技术图、CAD 风
> 气质：精密、可信、工程感。
> 出身：建筑施工图、专利图。

```css
--bg:#0d2b4d; --ink:#e8f2fc; --sub:#7fb0dc; --accent:#4da3ff; --line:rgba(160,205,245,.22);
/* 全部等宽字 */
```
**签名手法**：双层网格（细 20px + 粗 100px）铺满；带箭头的尺寸标注线标住主标题的宽度；
右下角一个图框标题栏（表格式，写比例/日期/编号）；关键位置打十字定位标记 `+`。
**常用画幅**：5:2 横幅 · 1.91:1
**适合**：技术内容、架构图、规格说明、开发者向。

### `archive` 档案手稿 · Archive
> 别名：手稿、卷宗、打字机、旧文件
> 气质：人味、时间感、一手材料。
> 出身：档案袋、实验记录本、打字机稿。

```css
--bg:#e7dfcd; --ink:#33302a; --sub:#7d7562; --stamp:#9b3227; --line:#c4b99f;
/* 打字机等宽为主 */
```
**签名手法**：一枚旋转 -8° 的方框印章（双线边框、大写字距）；左侧一列装订孔（等距圆点）；
表单式的字段行（标签 + 下划线）；纸张噪点开到 .5 以上。
**常用画幅**：1:1 方图 · A4
**适合**：复盘、记录、个人项目、年度总结、复古主题。

## 艺术运动

### `bauhaus` 包豪斯 · Bauhaus
> 别名：构成主义、几何、三原色
> 气质：大胆、结构清晰、有历史重量。
> 出身：1919 魏玛包豪斯；Herbert Bayer 的海报。

```css
--bg:#f2efe6; --ink:#141414; --red:#e63329; --yellow:#f7c400; --blue:#1b4bd8;
/* 几何无衬线，字重 700+ */
```
**签名手法**：三个基本形（圆 / 三角 / 方）各占一个色，尺寸差异极大地构成画面；
文字压在色块交界处；用 `mix-blend-mode:multiply` 让重叠处生成第四色。**三原色不能加第四种颜色**。
**常用画幅**：3:4 · 9:16 海报
**适合**：活动海报、课程、艺术类、封面。 **不适合**：严肃 B 端。

### `deco` 装饰艺术 · Art Deco
> 别名：Art Deco、复古奢华、盖茨比、二十年代
> 气质：华丽、对称、盛大。
> 出身：1925 巴黎装饰艺术博览会；克莱斯勒大厦。

```css
--bg:#0f1c18; --ink:#f5efe3; --gold:#d9b26a; --line:rgba(217,178,106,.45);
/* 细高衬线，全大写，字距 .18em 以上 */
```
**签名手法**：顶部一组放射状扇形（`conic-gradient` 或多条旋转细线）；双线边框（外粗内细，间距 6px）；
严格左右对称；金色只用在线条和小字，不用在大面积。
**常用画幅**：9:16 邀请函 · 3:4
**适合**：活动邀请、周年、颁奖、高端餐饮/酒。

### `riso` 双色印刷 · Risograph
> 别名：Riso、孔版印刷、叠印、错版
> 气质：手作、年轻、独立出版。
> 出身：日本理想科学的孔版印刷机；zine 文化。

```css
--paper:#f2efe6; --c1:#ff4f38; --c2:#2b4bff;  /* 两个荧光色，multiply 叠印 */
```
**签名手法**：同一个形状印两遍，两色**故意错位 6~10px**；重叠区用 `mix-blend-mode:multiply` 生成暗紫；
粗颗粒噪点（opacity .5+）；纸张边缘留不齐的白边。**只用两个颜色**，第三色必须来自叠印。
**常用画幅**：3:4 · 9:16 海报
**适合**：音乐/展览/市集海报、青年向、封面。

### `brutalist` 粗野主义 · Brutalism
> 别名：粗野、反设计、裸露、web brutalism
> 气质：直接、不装、有攻击性。
> 出身：混凝土建筑；Bloomberg 改版、Balenciaga 官网。

```css
--bg:#ffffff; --ink:#000000; --accent:#ff3b00;
/* 故意用系统默认字：Times New Roman + Courier 混排 */
```
**签名手法**：3~4px 纯黑实边框的方块，**故意重叠错位**；文字加下划线；
元素旋转 1~2° 制造"没对齐"；大字直接顶到画板边缘出血。零圆角、零阴影、零渐变。
**常用画幅**：1.91:1 · 1:1
**适合**：宣言、观点、亚文化、开发者向。 **不适合**：需要信任感的商业场景。

### `memphis` 孟菲斯 · Memphis
> 别名：八十年代、撞色几何、Memphis Milano
> 气质：吵闹、好玩、青春。
> 出身：1981 米兰 Memphis 设计集团；早期 MTV。

```css
--bg:#f7f3ea; --ink:#141414; --mint:#4fd1c5; --coral:#ff6b6b; --lemon:#ffd93d; --grape:#7c5cff;
```
**签名手法**：三种几何碎片同时出现——斜条纹色块、波浪线（`repeating` + `border-radius`）、
散落的实心圆点；它们**从画板边缘切进来**而不是完整摆在中间；黑色粗字压在最上层。
**常用画幅**：1:1 · 3:4
**适合**：活动、潮流、年轻向、娱乐。

## 东方

### `wabi` 日式侘寂 · Wabi-sabi
> 别名：日式、极简日系、无印感、留白
> 气质：安静、克制、有呼吸。
> 出身：茶道美学；原研哉、无印良品。

```css
--bg:#e9e3d6; --ink:#2b2723; --sub:#8b8375; --seal:#b3402f; --line:#cfc7b6;
```
**签名手法**：留白 **65% 以上**，主体压在画板的下三分之一或右侧；
一列竖排小字（`writing-mode:vertical-rl`）；一枚 60px 见方的朱红印章；
所有线条是 1px 且长度不满（故意不到头）。**不要填满任何东西**。
**常用画幅**：1.91:1 · 3:4
**适合**：生活方式、茶/器物、读书、慢内容、展览。

### `ink` 中式水墨 · Ink Wash
> 别名：水墨、国风、宣纸、书法
> 气质：写意、有文气。
> 出身：文人画；宣纸与墨的浓淡。

```css
--paper:#f5f1e8; --ink:#1a1a18; --wash:rgba(26,26,24,.16); --seal:#8c1f1f;
/* 标题用宋体/楷体，落款用小号宋体 */
```
**签名手法**：墨晕——一个大的不规则形（`border-radius:48% 52% 61% 39%/…` + `filter:blur(30px)`
+ 低透明度墨色）作为背景；标题竖排在右上；朱红方印落在左下；宣纸纤维用极细噪点。
**常用画幅**：3:4 · 9:16
**适合**：文化内容、节气、诗词、茶酒、中式品牌。

### `guochao` 国潮 · Neo-Chinese
> 别名：国风、新中式、中国红、节庆、年味
> 气质：热闹、有仪式感、传统但不老气。
> 出身：老月份牌、传统回纹与如意云、朱砂印。

```css
--bg:#b81c22; --ink:#f7e9c8; --gold:#e0b76a;
/* 标题楷体或宋体加粗，可用繁体增加古意 */
```
**签名手法**：双线金边框 + 四角直角包边（只有两条边的 L 形角标）；
竖排书法标题压右；如意云线条（SVG path 的连续弧）压左下；一枚方框印章。
金色**只用在线条和小字**，大面积保持红底金字。
**常用画幅**：9:16 · 3:4
**适合**：春节/中秋、国风品牌、茶酒、中式餐饮、文创。

## 手作与纸感

### `sketch` 手绘 · Hand-drawn
> 别名：手绘、涂鸦、白板、笔记、草图、马克笔
> 气质：亲切、没有距离感、像有人在给你讲。
> 出身：会议白板、笔记本、Excalidraw。

```css
--bg:#fdfcf8; --ink:#2b3a55; --sub:#8493ab; --marker:#ffe066; --pen:#ff7b6b;
--hand:"Hanzipen SC","Hannotate SC","Marker Felt",sans-serif;  /* macOS 自带中文手写体 */
```
**签名手法**：所有线条都要**抖**——用 `feTurbulence + feDisplacementMap` 把矩形/箭头/勾选框的
边缘打散（scale 4~7）。荧光笔高亮是一条**歪 1.5° 的色带**压在文字下层（`mix-blend-mode:multiply`）。
再配手绘流程图小方块、手写批注、便签贴纸。
**关键**：一页手绘笔记要**填得满**——空荡荡的手绘看起来像没画完，不像克制。
**常用画幅**：1.91:1 · 16:9 · 3:4
**适合**：教程、科普、产品讲解、脑图、亲和力优先的内容。

### `chalk` 黑板 · Chalkboard
> 别名：黑板报、粉笔、教室、菜单板
> 气质：温暖、日常、有人手写的痕迹。

```css
--bg:#26332e; --ink:#eef3ee; --sub:#9dbfae;
--hand:"Hanzipen SC","Chalkboard SE",sans-serif;
```
**签名手法**：整层粉笔灰（噪点 `mix-blend-mode:screen`，opacity .3）；
文字加 `text-shadow:0 0 1px rgba(255,255,255,.5)` 模拟粉笔的松散边缘；
标题下面一条手绘抖动的白线（同 sketch 的湍流做法）。
**常用画幅**：1:1 · 3:4
**适合**：课程、菜单、教学、社群公告、每日一句。

### `watercolor` 水彩 · Watercolor
> 别名：水彩、晕染、透明水色、疗愈
> 气质：柔软、有呼吸、手作温度。

```css
--bg:#fbf8f2; --ink:#2f2b26; --c1:#6fb0dc; --c2:#f5a288; --c3:#9ec98a;
```
**签名手法**：三块湍流位移的椭圆，`mix-blend-mode:multiply` 叠印，
**但只让它们小部分重叠**——三色大面积叠加会变成浑浊的灰绿，这是水彩最容易翻车的地方。
opacity 控制在 .34~.46，blur 4~5。文字压在左侧留白区，不要压在色块上。
**常用画幅**：3:4 · 1:1
**适合**：生活方式、疗愈、绘本、手作、季节内容、香氛。

### `collage` 拼贴 · Collage / Cut-out
> 别名：剪贴、杂志拼贴、撕纸、胶带
> 气质：手工感、随性、有生活痕迹。
> 出身：Zine、剪报、手账。

```css
--bg:#e9e3d6; --paper:#fbf9f4; --ink:#1c1a17; --red:#e8503a; --yellow:#f0d678;
```
**签名手法**：标题**每个字单独一个块**，各自不同底色、不同字体、各转 1~3°，像从杂志上剪下来贴的；
纸片边缘用 `clip-path: polygon(...)` 做不规则撕边；半透明黄色胶带（两侧虚线边）压住纸角。
**常用画幅**：3:4 · 1:1
**适合**：杂志感封面、活动、播客、青年文化、手账。

### `botanical` 博物图鉴 · Botanical Plate
> 别名：植物图鉴、博物学、标本、复古科学插画
> 气质：体面、有学识、安静的复古。
> 出身：十九世纪植物图谱、《柯蒂斯植物学杂志》。

```css
--bg:#f4f1e6; --ink:#2b3327; --line:#b9b49e; --leaf:#5c6b4f; --label:#faf8f0;
/* 全部衬线。拉丁学名用 italic */
```
**签名手法**：双层细线内框（间距 6px）把整张图裱起来；右侧一株 1.6px 细线描的植物
（主茎 + 对生叶片，叶片填 `fill-opacity:.22` 的淡绿）；右下角一张标本标签（细线框 + 字段表）；
标题下面一行**斜体拉丁学名**；角落一个 `FIG. 04` 编号。
**常用画幅**：3:4 竖版 · A4
**适合**：自然、香氛、茶饮、科普、复古品牌、植物类电商。

## 流行文化

### `comic` 美漫波普 · Comic / Pop Art
> 别名：漫画、波普、半调网点、Lichtenstein
> 气质：吵、有冲击力、一眼看到。

```css
--bg:#ffd93d; --ink:#111; --red:#ff2e4c; --paper:#fff;
```
**签名手法**：半调网点铺底（`radial-gradient` 平铺 23px）；标题白字 + `-webkit-text-stroke:6px` 黑描边
+ `text-shadow:8px 8px 0 #111` 硬投影；一个多角爆炸星（`clip-path` 20 点多边形）放拟声词；
底部一个带尖角的对话框。
**常用画幅**：1:1 · 3:4
**适合**：强冲击标题、活动、玩梗内容、促销。

### `pixel` 像素 · Pixel / 8-bit
> 别名：像素风、8bit、复古游戏、红白机
> 气质：极客、怀旧、好玩。

```css
--bg:#1a1c2c; --fg:#f4f4f4; --y:#ffcd75; --o:#ef7d57; --g:#38b764; --b:#41a6f6;
```
**签名手法**：像素切角——用 `clip-path` 的阶梯 polygon 给方块砍掉 12px 见方的四角；
标题用**四向硬描边**（`text-shadow` 上下左右各 5px 实色）+ 10px 硬投影，绝不用模糊阴影；
再配 8-bit 图标（SVG + `shape-rendering="crispEdges"`）、血条式进度条、带 ▼ 的对话框。
中文没有像素字，**像素感靠边框和描边做，不靠字体**。
**常用画幅**：16:9 · 1:1
**适合**：游戏、独立开发、复古数码、社群活动。

### `y2k` 千禧 · Y2K
> 别名：千禧风、2000年代、辣妹、chrome、金属
> 气质：闪、甜、怀旧的未来感。

```css
--bg:linear-gradient(150deg,#bcd2ff,#e3ccff 42%,#ffc9e8); --ink:#3a3f66;
```
**签名手法**：chrome 金属字——`background:linear-gradient(180deg,…)` 做**高对比多段**渐变
（白→浅蓝→深蓝灰→在 50% 处急转纯白→再压深→回白），配 `background-clip:text`；
描边用四向 `drop-shadow(1.5px 0 0 …)` 叠出来（`text-stroke` 会盖住渐变）。
再加四角星闪（`clip-path` 八边形）、果冻半球、细网格。
**常用画幅**：3:4 · 1:1
**适合**：潮流、美妆、音乐、怀旧向、Z 世代。

### `vapor` 蒸汽波 · Vaporwave
> 别名：蒸汽波、синтвейв、复古电子、赛博落日
> 气质：迷幻、怀旧、亚文化暗号。

```css
--bg:linear-gradient(180deg,#2b1055,#6d2bd9 34%,#ff6ec7 66%,#ffc36e);
```
**签名手法**：三件套缺一不可——① 日落圆（黄→橙→粉竖向渐变）被几条底色横条切开；
② 透视网格地平线（`transform:perspective(300px) rotateX(65deg)`）；
③ 标题**全角字距**（`letter-spacing:.26em`）+ 青品双色硬投影。
**常用画幅**：1:1 播客封面 · 9:16
**适合**：音乐、播客封面、复古电子、亚文化。

### `neon` 霓虹赛博 · Neon / Cyberpunk
> 别名：霓虹、赛博朋克、夜店、发光
> 气质：夜、锐利、都市。

```css
--bg:#08060f; --cyan:#00fff0; --magenta:#ff2d95;
```
**签名手法**：霓虹发光是**四层递进的 text-shadow**——
`0 0 5px, 0 0 16px, 0 0 42px, 0 0 88px`，透明度依次降低，只有这样才像灯管而不是模糊；
底部透视网格地平线，上面盖一层从底色到透明的渐变让它"淡出"。
**常用画幅**：16:9 · 1.91:1
**适合**：夜生活、游戏、直播、科技感强的活动。

### `street` 街头海报 · Street / Flyposting
> 别名：街头、贴纸、喷漆、地下、punk
> 气质：粗粝、有态度、不修边幅。

```css
--bg:#dcd8ce; --paper:#f2efe7; --ink:#141414; --acid:#d6ff3d;
```
**签名手法**：多层撕边纸片（`clip-path` 不规则多边形）错位堆叠；
整层喷漆噪点（`feTurbulence` + `mix-blend-mode:multiply`，opacity .3）；
所有文字块**各转 -2°~-1°**，标题关键词整块反白成荧光色；一个粗边框的模板喷字标记。
**常用画幅**：9:16 · 3:4
**适合**：演出、滑板、潮牌、地下活动、宣言。

## 影像与商业

### `cinematic` 电影海报 · Cinematic
> 别名：电影感、大片、A24、纪录片
> 气质：庄重、有距离、有分量。

```css
--bg:#08080a; --ink:#f2f0ec; --sub:#8d867a;
```
**签名手法**：底部一整块**密集的 credits 小字**（10px、全大写、`transform:scaleX(.86)` 压窄、
居中、行距紧）——这一块才是电影海报的辨识度所在，比标题重要；
标题用衬线 + `letter-spacing:.2em` 居中；顶部一行 tagline；中间大面积留空 + 一处极淡的暖光晕。
**常用画幅**：9:16 · 1.91:1
**适合**：纪录片、活动预告、年度总结、品牌大片。

### `retro70` 复古未来 · Retro 70s
> 别名：七十年代、复古、橙棕、彩虹条
> 气质：温暖、乐观、有年代感。

```css
--bg:#f3e3c3; --ink:#5a2f1c; --o:#e0672f; --y:#d9a441; --br:#8c4a2f;
--round:"Yuanti SC","PingFang SC",sans-serif;   /* 圆体是这套的关键 */
```
**签名手法**：右侧一整条三色竖向彩虹带，用一个底色的**半椭圆**（`border-radius:0 100% 100% 0/0 50% 50% 0`）
咬进去，做出 70 年代的弧形切口；标题必须用圆体，字重 900。
**常用画幅**：1:1 · 3:4
**适合**：咖啡/餐饮、市集、复古品牌、播客。

### `lineart` 极简线条 · Line Art
> 别名：线描、单线、极简插画、几何线
> 气质：冷静、克制、专业。

```css
--bg:#fcfbf8; --ink:#1e1e1c; --sub:#7d786e; --dot:#c2482f;
```
**签名手法**：右半张画板放**一个用 1.2px 细线构成的几何图形**（圆 + 曲线 + 十字轴），
线条要连续、有对称性；图形中心点一个小的实心色点作为唯一的颜色。
文字全部压左，字重 300，留白 55%+。
**常用画幅**：5:2 · 1.91:1
**适合**：咨询、金融、建筑、高端服务、年报。

### `glass` 玻璃 · Glass
> 别名：玻璃拟态、毛玻璃、glassmorphism、透明卡片
> 气质：轻、通透、当代产品感。
> ⚠️ `backdrop-filter` 在页内导出**不会被渲染**。下面的做法两条通道都稳。

```css
--bg:linear-gradient(140deg,#101a2e,#1b2b45 46%,#22364f); --fg:#eef3fa;
```
**签名手法**：不靠 `backdrop-filter`，而是在卡片**下面**单独放几个 `filter:blur(58px)` 的彩色圆
充当被折射的光；卡片本身是 `linear-gradient` 的半透明白 + `1px solid rgba(255,255,255,.22)` 描边
+ `inset 0 1px 0 rgba(255,255,255,.42)` 顶部高光。这三层缺一不可。
**常用画幅**：1.91:1 · 16:9
**适合**：SaaS、App 落地页、暗色产品图、发布公告。

## 数字原生

### `terminal` 终端 · Neo-Terminal
> 别名：命令行、CLI、极客、黑客
> 气质：技术、锐利、不废话。

```css
--bg:#0b0d0c; --fg:#e8ffe9; --accent:#4ade80; --dim:#5f6b62;
/* 全等宽。琥珀变体：--accent:#ffb000 */
```
**签名手法**：左侧一条 10px 荧光色带贯穿全高；眉标用 `▸` 或 `$` 起头、全大写、字距 .22em；
关键词整块反白（背景荧光色、文字近黑）；末尾一个实心方块光标。
可选一层极淡的扫描线（`repeating-linear-gradient` 2px 间隔，opacity .04）。
**常用画幅**：2.35:1 公众号 · 1.91:1
**适合**：技术内容、changelog、代码图、开发者向。

### `aurora` 极光 · Aurora
> 别名：渐变、光晕、氛围感、深色渐变
> 气质：当代、柔和、有空气感。
> ⚠️ 这是最容易做出 AI 味的一套。**下面三条不是建议，是纪律。**

```css
--bg:#0a0d12; --fg:#eef1f6; --sub:#8a93a6;
/* 渐变必须避开紫→蓝。用这两组之一： */
/* A 青→琥珀: rgba(45,212,191,.30) → rgba(251,191,36,.18) */
/* B 深绿→珊瑚: rgba(16,185,129,.26) → rgba(251,113,133,.16) */
```
**签名手法**：整张图**只有一处**光晕，且被画板边缘裁掉一半；
光晕上必须叠一层噪点（opacity .35+）消除色带；所有卡片/分区用 `1px solid rgba(255,255,255,.08)`
描边而不是阴影；留白 50% 以上。
**纪律**：① 不用紫蓝渐变 ② 渐变不做文字 ③ 光晕不超过一处。
**常用画幅**：1.91:1 OG · 5:2
**适合**：SaaS、AI 产品、OG 图、暗色主题。

### `luxe` 奢侈品 · Luxe
> 别名：高奢、黑金、时尚、极简奢华
> 气质：贵、安静、有距离感。
> 出身：Chanel/Hermès 的平面；时装大片的字幕排版。

```css
--bg:#0a0a0a; --ink:#f0ece4; --metal:#b08d57; --line:rgba(240,236,228,.22);
/* 细衬线（font-weight:300），全大写，字距 .3em 以上 */
```
**签名手法**：主标题用**细**衬线 + 全大写 + `letter-spacing:.28em`，居中，字号反而不必很大；
上下各一根 1px 金属色线，线与字之间留 40px 以上；除此之外**画面上什么都没有**。
留白 70%。克制本身就是这套风格的内容。
**常用画幅**：3:4 · 9:16
**适合**：品牌、时尚、香氛、高端活动、周年。 **不适合**：信息量大的图。

### `product` 极简产品 · Product Minimal
> 别名：SaaS、干净、现代、Apple 风
> 气质：清楚、可信、无摩擦。

```css
--bg:#fbfbfd; --ink:#14151a; --sub:#5b6070; --accent:#2f5cff; --line:#e6e8ef;
```
**签名手法**：留白 55%+；层次靠**明度差 4~8%** 的色块而不是阴影；
需要阴影时用三层递进（`0 1px 2px rgba(0,0,0,.04), 0 4px 12px rgba(0,0,0,.03), 0 12px 32px rgba(0,0,0,.02)`）；
界面示意全用纯 CSS 方块和线条画，不贴截图。强调色只用在一个交互元素上。
**常用画幅**：1.91:1 · 16:9
**适合**：功能发布、B端、文档配图、数据卡。

## 用户指定了库里没有的风格

按这四步把参照物拆成 token：

1. **取 4 个色**：底色 / 主文字 / 次要文字 / 一个重音色。从参照物里数——超过 5 个颜色说明你没看准。
2. **定字体反差**：哪一对在打架？（衬线 vs 等宽 / 900 vs 300 / 全大写宽字距 vs 常规）
3. **找签名手法**：这个风格**独有的那一招**是什么？一条线？一个形状？一种错位？没找到就别动手。
4. **定留白比例**：35% / 55% / 70%，三选一。

然后照 `design.md` 的排版和构图规则实现。

## 推荐话术（用户问"有什么风格"时）

挑 3~4 个跟他内容气质最近的报出去，一句话一个，别念全表：

- **瑞士国际主义** —— 白底红黑、严格网格，看起来"正确"。产品和数据的安全牌。
- **杂志编辑部** —— 米白纸、衬线大标题、首字下沉，像一本值得读的刊物。
- **工程蓝图** —— 深蓝网格、尺寸标注线，技术内容一秒可信。
- **包豪斯** —— 红黄蓝三原色几何构成，有历史重量又不老气。
- **双色印刷 Riso** —— 两个荧光色故意错版叠印，独立出版的手作感。
- **粗野主义** —— 粗黑边框、故意不对齐，适合有攻击性的观点。
- **日式侘寂** —— 留白七成、一枚朱红印章，安静得很贵。
- **中式水墨** —— 宣纸墨晕、竖排标题，国风但不土。
- **装饰艺术** —— 墨绿配金线、放射扇形，二十年代的盛大感。
- **终端** —— 近黑配荧光绿等宽字，开发者一眼认亲。
- **奢侈品** —— 纯黑、细衬线大写宽字距，画面上几乎什么都没有。
- **孟菲斯** —— 撞色几何碎片乱入，八十年代的吵闹。
- **手绘** —— 手写体配抖动的线框和荧光笔，像有人在白板上给你讲。
- **黑板** —— 墨绿底粉笔字，教室和菜单板的温度。
- **水彩** —— 三色晕染叠印，柔软透亮，适合疗愈和季节内容。
- **拼贴** —— 每个字剪下来单独贴，配胶带和撕纸边。
- **博物图鉴** —— 细线框、植物线描、拉丁学名，复古科学的体面。
- **美漫波普** —— 半调网点、爆炸星、粗黑描边，吵得有理。
- **像素** —— 8-bit 切角和硬描边，红白机的怀旧。
- **千禧 Y2K** —— chrome 金属字配星闪果冻，2000 年的甜。
- **蒸汽波** —— 日落圆、透视网格、全角字距，亚文化暗号。
- **霓虹赛博** —— 四层发光的灯管字，都市夜。
- **街头海报** —— 撕贴、喷漆、歪着贴，有态度。
- **电影海报** —— 底部一整块密集 credits，庄重有分量。
- **复古未来 70s** —— 橙棕彩虹带配圆体，温暖乐观。
- **极简线条** —— 一个细线几何图形加大量留白，冷静专业。
- **玻璃** —— 通透卡片配折射光斑，当代产品感。
- **国潮** —— 红底金线、竖排书法、如意云，年味十足。
